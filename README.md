# 創業星系

Ray 手上正在轉的專案，用一張互動星圖呈現。

點任一顆星球會進入該專案的「宇宙」頁，顯示簡介、關鍵欄位與底下的子項目。按 `←` 返回星系或 `Esc` 關閉。

星球的大小代表投入程度，離中心的距離代表離日常的遠近。

## 要改內容

所有資料都在 `index.html` 底部 `<script>` 裡的 `PLANETS` 陣列，一顆星球一個物件：

- `r` — 離中心的距離（百分比）
- `size` — 直徑（百分比）
- `angle` / `speed` — 起始角度與公轉速度
- `lede` / `meta` / `moons` — 宇宙頁的內容

沒有 build 步驟，改完直接 commit 即可。
